## 🌟 关于易合成 (AIPHACAS)

易合成（AIPHACAS）致力于以人工智能、大数据及云原生基础设施重构传统的化学与药物研发流程，终结研发环节中工具割裂、数据离散的“拼凑式”体验。

我们为科研院所、高校、创新药企与精细化工企业提供从**分子设计、机理逆合成、反应检索、电子实验记录（ELN）到智能物料流转**的全链路闭环系统，助力科研团队百倍提升合成路线探索与药物研发转化效率。

## 🛠️ 技术底座与算法栈

我们依托第一性原理进行底层技术创新，深度结合科学计算与前沿软件工程架构：

- **AI & 算法**：EditRetro、Fairseq C++ 算子加速、图神经网络（GNN）、Transformer 序列模型、RDKit 化学信息学引擎
- **云原生基础设施**：Kubernetes (K8s)、Docker/Kaniko、Nginx Ingress、动态 GPU 显存切分与调度
- **工程与微服务**：Python (FastAPI / PyTorch)、Go、React 18 / Ant Design、PostgreSQL、Redis、MinIO S3
- **安全与合规**：RBAC 多租户权限隔离、企业级 SSO / OIDC 单点登录、端到端行为审计与访问风控
